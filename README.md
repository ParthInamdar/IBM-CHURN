Telecom Customer Churn Analysis

Objective:
Analyze telecom customer churn patterns and identify business factors influencing customer retention.

Tools:
- Python
- Pandas
- NumPy
- Matplotlib

Key Findings:
- Month-to-month contracts had the highest churn.
- Customers with shorter tenure churned more.
- Higher monthly charges were associated with increased churn.
- Fiber optic customers showed higher churn rates.

Business Impact:
Provided recommendations to improve customer retention and reduce churn.
